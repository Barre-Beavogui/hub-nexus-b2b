# Hub Nexus B2B

Site vitrine B2B multilingue pour une entreprise d'intermediation commerciale reliant fournisseurs, distributeurs, prestataires de services et acheteurs professionnels.

## Contenu

- `index.html` : structure de la landing page
- `styles.css` : design responsive et identite visuelle
- `app.js` : traductions dynamiques et gestion du formulaire de contact

## Lancer en local

```bash
python3 -m http.server 4173 --directory .
```

Puis ouvrir `http://127.0.0.1:4173/index.html`.

## Contact

Le formulaire est configure pour envoyer les demandes vers `barre.beavogui@icloud.com` via FormSubmit.
